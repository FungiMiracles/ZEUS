# ZEUS-GAME-0004 — handel

Zakres: wyłącznie ZEUS_UAT.

## WYM0037

W formularzu oferty dodano amunicję przeciwrakietową (`interceptor_ammunition`, ikona AMMO). Jest to rzeczywisty magazyn `ResearchAccount.ammunition`, współdzielony z produkcją fabryk i uzupełnianiem obrony. Wystawienie oferty rezerwuje amunicję przez odjęcie jej od dostępnego magazynu. Wycofanie zwraca ją raz; zakup nie udostępnia jej kupującemu do czasu dopłynięcia statku. Dostawa zasila magazyn amunicji, a nie magazyn surowców. Można tworzyć pakiety mieszane. Produkcja z zakończonych dni Entendy jest uwzględniana przed wystawieniem oferty.

Oferty zawierające amunicję są niedostępne dla państw w relacjach „złe”, „wrogie”, „egzystencjalnie wrogie” lub stanach wojny hybrydowej, okupacji i wojny kinetycznej, w tym zamrożonej. Uwzględniane są wpisy relacji w obu kierunkach. Wymaganie nie blokuje zwykłego handlu surowcami. Ograniczenia sprawdzane są ponownie pod blokadami przy zakupie, więc zmiana dyplomacji po otwarciu ekranu nie pozwala ich obejść. Wycofanie własnej oferty nadal jest dostępne. Ładunki już zakupione podlegają dotychczasowym regułom transportu i zatopienia.

## WYM0038

Nie można dodać państwa sojuszniczego, partnerskiego ani partnerskiego strategicznego do listy blokad portowych. Kontrolki tych państw są wyłączone, a API odrzuca próbę ich ręcznego zablokowania. Blokada ogólna ma jawny wyjątek dla sojuszników i partnerów. Wyjątek działa także przy starych zapisach selektywnej blokady oraz po późniejszej zmianie relacji. Przy zakupie dostęp jest ponownie sprawdzany. Pozostałe państwa nadal podlegają blokadom.

## WYM0039

API dostaw udostępnia `deliveredAt`. Zakończone dostawy w „Moich dostawach” pokazują „Dostarczono (Entenda)” z datą i godziną symulacji. Nowe rozliczenia zapisują moment dopłynięcia (`arrives_at`), również gdy dostawę przetworzono z opóźnieniem. Dotychczasowe daty zakończonych dostaw nie są przeliczane wstecz.

## WYM0040

Zakup tworzy jedno powiadomienie SYSTEM dla sprzedawcy, obejmujące nazwę kupującego, ilości i rodzaje towarów, cenę oraz potrąconą opłatę eksportową (także zero). Powiadomienie ma ikonę `CARGO SHIP.svg`; jego otwarcie prowadzi do handlu. Powiadomienie, przepływy pieniężne, zmiana statusu oferty i utworzenie dostawy są jedną transakcją. Ponowienie tego samego zakupu nie powiela wiadomości ani płatności.

## Weryfikacja

- 10 nowych testów: rezerwacja/wycofanie, wspólny magazyn amunicji, mieszany ładunek i dostawa dokładnie raz, wszystkie wskazane blokady dyplomatyczne (w tym relacja odwrotna), wyjątki portowe, powiadomienie z eksportowym cłem, ikona i odnośnik, rollback, zatopienie oraz rozliczona produkcja fabryki.
- 14 testów handlu/wydobycia, 18 portów i finansów, 7 tras morskich i walki z transportem, 22 forum/powiadomień, 13 badań/podatków — łącznie 84 testy zakończone powodzeniem.
- Chromium na izolowanej bazie: wystawienie amunicji, rezerwacja, zakup przez inne państwo, dostawa do właściwego magazynu i data symulacji na karcie, wyłączona blokada sojusznika, układ 390 px; bez operacji na bieżącej rozgrywce.
- Kontrola składni Python, JS i Jinja.

Zmiany wykorzystują istniejące magazyny, pola JSON i powiadomienia SYSTEM. Migracja schematu nie jest potrzebna. Zaktualizowano cache JS i przeładowano tylko Gunicorn ZEUS_UAT.

Po przeładowaniu ekran i API stanu handlu zwróciły HTTP 200. Sprawdzono katalog i stan magazynu amunicji, metadane ochrony sojuszników, pole daty dostarczenia oraz nowe JS i ikonę transportowca. Kontrola działającej usługi nie wystawiała ofert ani nie dokonywała zakupów.
