# ZEUS GAME UAT — ikony produktów w lewym górnym rogu

Środek małej ikony produktu znajduje się w lewym górnym rogu dużej ikony fabryki. Dotyczy katalogu, kart obiektów i mapy infrastruktury. CSS ui14. Izolowany Chromium potwierdził położenie pomiarami obu ikon w trzech miejscach. Wdrożono przez HUP zeus_uat.service.
