# ZEUS UAT — koszt punktów pod formularzem na telefonie

Do 600 px pole liczby punktów i Kup zajmują pierwszy wiersz, a dynamiczny koszt ROI pełną szerokość drugiego wiersza. Desktop zachowuje dotychczasową kolejność. CSS ui22. Izolowany Chromium 390/600/1440 px potwierdził pozycje, wyrównanie kontrolek, aktualizację kosztu po wpisaniu liczby i brak poziomego przewijania. Wdrożono przez HUP Gunicorn UAT.
